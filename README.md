# IT School Web Page

## Description
This is a static web page for an IT School, created entirely using HTML and CSS.  
The page presents information about the school, the courses offered, and contact details.  
It was developed as a Front-End learning project to practice HTML structure and styling with CSS.

## Technologies Used
- HTML5  
- CSS3  

## Features
- Clear and organized layout  
- Semantic HTML structure for accessibility  
- Styled with CSS for visual appeal  
- Sections about the IT School, courses, and contact information  

## Project Structure
- `proiect.html` – Main HTML file  
- `style.css` – CSS styling file
